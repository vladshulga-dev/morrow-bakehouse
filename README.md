# Morrow Bakehouse

Morrow Bakehouse is a responsive one-page website for an artisan bakery. The design puts signature pastries and product photography first, keeps the selection easy to scan, and gives customers a clear path from discovering the bakery to planning a visit.

The site is built for small bakeries and pastry shops that need a polished digital presence without the weight of a large multi-page website. Editorial typography, generous product imagery, seasonal storytelling, and practical service details create a warm experience that still feels focused and easy to use.

## Key features

- Product-focused bakery showcase
- Responsive desktop and mobile layout
- Signature pastry selection with aligned cards
- Bakery story and seasonal content sections
- Click-to-expand product photography
- Mobile navigation and overflow-safe layout
- Clear hours and service information

## Stack

HTML, CSS, JavaScript
